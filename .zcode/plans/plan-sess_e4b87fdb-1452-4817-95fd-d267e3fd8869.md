# Conte interactif « Yennenga » — page-par-page, design story.pen, audio réel

## Contexte

L'utilisateur a fourni un prototype (`yennenga.zip`) : un conte interactif pour enfants de Yennenga (couverture + 6 chapitres) basé sur le design Pencil « story.pen — Voix du Faso » — palette nuit `#0E0B09` / crème `#F2E6D3` / braise `#E8743B` / ocre `#E0A84B` / latérite / indigo, fonts Fraunces + Hanken Grotesk + JetBrains Mono. Une scène SVG 16:9 (1600×900) où 8 calques (savane, Yennenga à cheval, roi, gombo, chasseur, forêt, mère+bébé, buisson) glissent entre les poses de chaque page, avec micro-tâches tactiles par chapitre (galoper, semer le gombo, allumer 5 étoiles, trouver le chasseur, saluer le bébé), anneau d'indication, navigation boutons + clavier, `prefers-reduced-motion`.

Décisions : **Yennenga uniquement** (les 2 autres récits gardent le scrollytelling actuel) ; le nouveau design vit dans ce nouveau mode (atlas + page récit inchangés ce tour) ; forme **page-par-page** comme l'exemple.

Apports vs prototype : la voix `speechSynthesis` du prototype est remplacée par **nos pistes TTS réelles** (moteur `useMultilingualAudio` injecté — lecture du chapitre correspondant à la page, sous-titre cue actif à la place du surlignage mot-à-mot), et le tout devient une **route Next pré-rendue** au lieu d'un fichier HTML isolé.

## Plan

### 1. Assets — calques Pencil dans `public/stage/yennenga/`

Copier les 8 SVG du zip inspecté (`.inspect/yennenga-exemple/svg/`) vers `public/stage/yennenga/` : `savane, yennenga, roi, gombo, chasseur, foret, mere, buisson`. Ajouter `.inspect/` à `.gitignore`. Les calques sont injectés **inline** (fetch → `dangerouslySetInnerHTML` dans des `<g>`) — obligatoire pour animer leurs classes CSS (bob, galop, poussière…). Petit hook `useStageLayer(name)` (fetch + cache module-level, pattern du préchargement blob du moteur audio).

### 2. Données scènes — `src/data/scenes/yennenga-mere-des-moose.json`

Portage fidèle du tableau `SCENES` du prototype en JSON typé : 7 pages (couverture + 6 chapitres) avec `chap`, `text` (les textes courts enfant du prototype — une idée par page ; l'audio long du corpus joue par-dessus), `task`, `sky`, `night`, `stars`, pose `sun`, poses `{x,y,s,o}` de `rider/king/hunter/mother`, `forest.x`, `act`. Type `StageScene[]` dans `src/types/story.ts` (ou fichier types dédié). Positions des étoiles, trous de gombo, buissons incluses. Association page N (1–6) → chapitre N−1 du corpus.

### 3. Composant — `src/components/InteractiveStory.tsx` (client)

Portage React du moteur du prototype :
- **Stage** 1600×900 `preserveAspectRatio slice` dans un cadre arrondi ; couches : ciel (fill animé), étoiles de fond, soleil, savane, voile nuit, forêt (translate), roi + bulle « Non ! », champ/`field`, chasseur, buissons, mère, cavalier (bob + poussière), anneau d'indication.
- **Pose engine** : le changement de page change `style.transform/opacity` des acteurs — les transitions CSS font glisser (même astuce que le prototype, retarget depuis la valeur courante).
- **6 interactions** portées (refs + classList, `getBBox` pour relancer les animations) : galop + poussière, secousse du roi + bulle, semis 3× → gombo pousse puis sèche, 5 étoiles → forêt + galop, buissons → chasseur découvert, câlin mère/bébé. Achèvement → `done`, nudge sur « suivant ».
- **Audio injecté** (prop `audio: MultilingualAudio`, owner = la page) : bouton « Écouter » = `goToChapter(page-1)` + `toggle()` ; changement de page pendant la lecture → seek du chapitre ; sous-titre cue actif affiché sous le texte ; pas d'auto-avance de page (le lecteur tient le rythme, nudge discret en fin de chapitre).
- **Navigation** : prev/next + flèches clavier + Entrée/Espace sur les cibles (roles button, `tabindex` sync), barre de progression, retour à la page 1 en fin.
- `prefers-reduced-motion` : animations coupées, transitions réduites à l'opacité.

### 4. Route — `src/app/recits/[id]/conte/page.tsx`

`generateStaticParams` sur les récits **ayant des scènes** (Yennenga seul) ; autres ids → `notFound()`. `generateMetadata` (« Conte interactif — Yennenga »). La page (client wrapper) possède l'unique `useMultilingualAudio({ story })` et le passe à `InteractiveStory` — même contrat d'injection que `StoryPlayerCard`.

### 5. Entrée/sortie — `StoryExperience.tsx`

Sur le hero de la page récit : bouton « ✨ Conte interactif » visible uniquement si des scènes existent pour le récit (simple table `hasInteractiveScenes`) → `/recits/[id]/conte`. Dans le conte : lien « ← Le récit » vers `/recits/[id]`.

### 6. Styles + fonts

- Bloc `.ikt` dans `globals.css` : portage du CSS du prototype (tokens locaux nuit/braise/ocre, poses, keyframes `bob/dust/shake/nuzzle/plant/star/bush/hint/ping/bubble/nudge`, carte « page » pagne avec rayures latérite, barre de progression, responsive 720 px, `prefers-reduced-motion`). Aucun token existant touché — l'atlas et le scrollytelling restent en olive/papier.
- `layout.tsx` : ajouter Fraunces (variable `--font-tale-display`), Hanken Grotesk (`--font-tale-ui`), JetBrains Mono (`--font-tale-mono`) via `next/font/google` — Playfair/Inter actuels conservés pour l'existant.
